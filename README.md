# ALTE Common Corpus SIG  
## European CEFR Vocabulary Atlas pilot

### Help shape a multilingual evidence base for vocabulary and the CEFR

The ALTE Common Corpus SIG is developing a proposal for a collaborative
multilingual pilot supporting the European CEFR Vocabulary Atlas.

The project explores how corpus evidence, concepts and senses,
language-specific lexical forms, communicative functions, expert judgement
and carefully governed AI-assisted analysis could be brought together across
European languages.

We are currently looking for prospective founding participants who would like
to help shape the research design, test the methodology and determine the
future direction of the pilot.

The initial languages are:

- English
- French
- Spanish
- German
- Czech

The approach is intentionally still open for discussion. Joining at this stage
means helping to define the project—not simply carrying out a process that has
already been fixed.
