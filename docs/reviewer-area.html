Reviewer warning: LLM-generated outputs are provisional Tier 4 candidate material and must not be treated as validated CEFR evidence.

Reviewer tasks

  1. Check whether the assigned sentence-level function is appropriate.
  2. Confirm that the whole sentence is being tagged, not only the sampled lemma.
  3. Flag uncertain or incorrect labels.
  4. Check whether the rationale is plausible.
  5. Mark rows requiring adjudication.
  6. Add comments where taxonomy choice is difficult or ambiguous.

Review statuses

StatusMeaning
provisionalPlausible candidate output needing later validation.
review_requiredUncertain, disputed, low-confidence, or potentially misaligned output needing expert attention.
