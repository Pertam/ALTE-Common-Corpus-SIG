Provisional candidate material — not validated CEFR data.
Current automated outputs are model-generated candidate material for expert review. They are not validated CEFR vocabulary data, not approved Atlas releases, and must not be cited as validated findings.

Purpose of expert review

Expert review distinguishes model output from expert judgement. Reviewers check whether the candidate function label fits what the whole sentence is doing in context.

How to review

  1. Read the sentence and sampled lemma.
  2. Inspect Pass 1, Pass 2 and any Pass 3 automated-resolution output.
  3. Choose accept, correct, reject, uncertain, insufficient context or multiple plausible functions.
  4. Enter corrected function ID only when changing the label.
  5. Write a short rationale for changes, rejection or uncertainty.
  6. Preserve identifiers and protected fields.
  7. Save and submit according to the confirmed process: PROJECT-LEAD DECISION REQUIRED.

Illustrative worked example

Sentence: Could you send me the report by Friday?

Candidate function: requesting action.

Expert decision: Accept.

Useful rationale: The sentence uses a question form to ask the listener to perform an action by a deadline.
