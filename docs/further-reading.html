Purpose of this page

This page collects external references and background reading relevant to the project. It replaces the earlier generic links page. The aim is not to provide a long bibliography, but to point readers towards the main frameworks and resources that inform the project.

CEFR framework and descriptors

Resource Why it is relevant Link
Common European Framework of Reference for Languages Core framework for describing language learning, teaching and assessment across levels. Council of Europe CEFR page
CEFR Companion Volume Updated CEFR publication with expanded descriptors, including mediation, online interaction and plurilingual/pluricultural competence. CEFR Companion Volume resources
Searchable CEFR descriptors Useful for checking how communicative functions and activities are expressed across CEFR levels. CEFR descriptor resources

Reference Level Descriptions

Resource Why it is relevant Link
Reference Level Descriptions Language-specific CEFR descriptions. These are important because the CEFR itself is language-general, while vocabulary and grammar have to be specified language by language. Council of Europe RLD page
Threshold level series Earlier CEFR-related language-specific descriptions that influenced later vocabulary and functional specifications. RLD components and forerunners

Corpus methods and vocabulary evidence

These topics are relevant to the project methodology and should be considered when developing later validation stages.

Topic Why it matters for the project
Frequency Helps identify common items, but does not determine CEFR level on its own.
Dispersion Shows whether an item is distributed across the corpus or concentrated in a narrow section.
ARF Supports sampling by combining frequency and distribution evidence.
Concordance analysis Allows reviewers to inspect real sentence environments and sense distinctions.
Learner corpus validation Can help compare predicted levels with learner production at different CEFR levels.
