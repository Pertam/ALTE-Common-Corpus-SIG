Project overview

The pilot tests how corpus evidence, lexical senses, language-specific forms, sentence-level communicative functions and expert judgement can be combined across English, French, Spanish, German and Czech.

The fundamental data unit is one target lemma occurrence in one sentence. Each row receives two distinct annotations: the sense of the target lemma and the communicative function of the whole sentence.

Sense and function are different

SentenceTargetLexical senseSentence function
Apply the cream twice daily.applyput a substance onto a surfacegiving an instruction
The rule applies to all applicants.applybe relevant or validstating a rule or condition

Sense belongs to the target lemma; function belongs to the sentence. Pass 1 produces them separately. Pass 2 then performs an informed critical review of both, while still recording a separate final decision for sense and function.

How the annotation passes work

PassPurposeInformation available
Pass 1Produce initial sense and function proposalsSentence, target lemma, approved sense inventory and function taxonomy
Pass 2Critically review, accept, change or flag the initial proposalsPass 1 sense, Pass 1 function and both rationales
Blind validation sampleEstimate reliability and possible anchoringOriginal inputs only; Pass 1 is hidden
Adjudication and expert reviewResolve selected difficult or changed casesFull annotation evidence and review history
