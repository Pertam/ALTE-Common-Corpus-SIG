What this project is

The ALTE Common Corpus SIG project is a methodological pilot supporting a future European CEFR Vocabulary Atlas. It tests whether multilingual corpus evidence, CEFR-derived communicative-function categories, large-language-model assisted sentence tagging and expert review can be combined in a transparent workflow.

The five pilot languages are English, French, Spanish, German and Czech. The intended long-term outcome is a validated, multilingual, evidence-based resource that helps describe vocabulary, functions, examples and cross-language differences in relation to CEFR use. That long-term outcome has not yet been achieved.

Workflow overview

  1. Prepare corpus inputs.
  2. Process text and compute statistics.
  3. Sample lemmas and sentences.
  4. Run Pass 1, Pass 2 informed validator pass and Pass 3 automated resolution pass.
  5. Prepare QA and review workbooks.
  6. Complete expert review, human adjudication, validation and approval before release.
