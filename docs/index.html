Project overview

This site documents the working infrastructure for the ALTE Common Corpus SIG contribution to the European CEFR Vocabulary Atlas pilot. The project explores how corpus evidence, CEFR-derived communicative functions, multilingual vocabulary alignment, LLM-assisted classification and expert review can be combined in a transparent workflow.

The aim is to move beyond simple word lists towards a richer model of vocabulary as concepts, senses, language-specific forms, corpus examples and communicative uses.

Current project focus

The current pilot focuses on five languages: English, French, Spanish, German and Czech. It connects corpus-derived lemma evidence with sentence-level communicative function tagging, then prepares outputs for review and later validation.

The work is especially concerned with preserving cross-linguistic differences rather than forcing equivalent-looking words into the same level or category.
