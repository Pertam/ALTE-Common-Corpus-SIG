What this project does

The ALTE Common Corpus SIG project develops a repeatable workflow for corpus preparation, lemmatisation, ARF-based sampling, sentence-level CEFR communicative function tagging, and expert review.

It supports the European CEFR Vocabulary Atlas pilot by creating a transparent technical pipeline that can be shared, inspected, repeated, and improved by SIG members.
