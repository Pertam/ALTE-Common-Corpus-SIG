About the project

Question Answer
What is the ALTE Common Corpus SIG project? It is a methodological pilot supporting the development of the European CEFR Vocabulary Atlas. The project explores how multilingual corpus evidence, CEFR-derived communicative functions, LLM-assisted classification and expert review can be combined into a transparent workflow.
Is the project creating a normal vocabulary list? No. The project is not simply listing words. It treats vocabulary as concepts, senses, language-specific forms, examples and communicative uses.
Why is the unit of analysis a concept or sense? Because one word form can have several meanings. For example, bank as a financial institution and bank as the side of a river are different concepts and should not be merged.
Why not just translate English words into other languages? The English label is only a working label. The real task is to identify the underlying sense and then find the most natural form or construction in each language.

CEFR and vocabulary judgement

Question Answer
Are CEFR vocabulary levels based only on frequency? No. Frequency is useful evidence, but CEFR judgement also depends on communicative usefulness, learner need, register, transparency, morphology, polysemy, production difficulty and domain.
What is the difference between receptive and productive CEFR? Receptive CEFR is the level at which a learner could reasonably understand an item in context. Productive CEFR is the level at which a learner could reasonably use it correctly and appropriately.
Can productive CEFR be lower than receptive CEFR? No. Productive CEFR should be the same as receptive CEFR or higher. Learners usually understand items before they can produce them accurately.
Can equivalent words have different CEFR levels in different languages? Yes. Cross-linguistic divergence is important data. Differences may be caused by cognate transparency, morphology, register, frequency distribution, constructional difficulty or polysemy.

Corpus evidence and sampling

Question Answer
What corpus evidence is used? The workflow can use sentence examples, lemma frequency, frequency per million, dispersion and ARF. These values help describe usage, but they do not automatically determine CEFR level.
Why use ARF? ARF helps reduce the influence of items that occur often but are concentrated in a narrow part of the corpus. It gives a more useful indication of distributed occurrence than raw frequency alone.
Why sample sentences for lemmas? Sentence samples show how a lemma behaves in context. They make it possible to inspect not just the word, but the communicative environments in which it appears.
Why does the project tag sentence functions? Function tagging shows what sentences are doing communicatively: requesting, explaining, reporting, evaluating, arguing, instructing and so on.

LLM-assisted classification

Question Answer
What does Pass 1 do? Pass 1 assigns an initial sentence-level function label using the controlled taxonomy.
What does Pass 2 do? Pass 2 validates the Pass 1 decision. It can accept the label, change it, or mark the row as uncertain.
What does Pass 3 do? Pass 3 adjudicates disagreement, low confidence or ambiguity and produces a final candidate label.
Why use more than one pass? Multiple passes reduce simple one-shot labelling. They make disagreement, uncertainty and ambiguity visible before expert review.
Does the LLM decide the final answer? No. LLM output is candidate material. Expert review and later validation are needed before any stronger claim can be made.

Reviewer questions

Question Answer
What should reviewers focus on first? For function tagging, reviewers should read the whole sentence and decide what it is doing communicatively. They should not tag only the sampled lemma.
When should a reviewer accept a row? Accept a row when the proposed label is defensible and no clearly better taxonomy label is available.
When should a reviewer change a row? Change a row when another function label, sense split or CEFR judgement is clearly better.
When should a reviewer mark uncertainty? Mark uncertainty when the sentence is ambiguous, the sense is unclear, the language equivalent is questionable, or the available taxonomy does not fit well.
What makes a good reviewer comment? A good comment is short but specific. For example: This reports a completed past event; it is not a request or instruction.

Using the data

Question Answer
How could the data support teaching? It could help with syllabus mapping, vocabulary sequencing, materials development, example sentence design and identifying gaps in course coverage.
How could the data support assessment? It could support test specification, item writing, text selection, vocabulary load checking, distractor review and cross-language comparability studies.
How could the data support classification? It could support sentence-function classification, text vocabulary-load profiling, concept-level CEFR candidate classification and review-priority classification.
Who might use the final resource? Potential users include curriculum designers, materials writers, teachers, test developers, researchers, policy teams and expert reviewers.

Technical and project structure

Question Answer
What is GitHub used for? GitHub stores code, scripts, notebooks, taxonomy files, documentation and the public GitHub Pages site. Prompt instructions are version-controlled inside the tagging scripts.
What is Google Drive used for? Google Drive stores larger working files: raw data, interim files, LLM outputs, logs, QA reports, review workbooks and exports.
What is Colab used for? Colab is the execution environment for cloning the repository, mounting Drive, checking paths and running scripts.
Where should I start? Start with the Rationale page, then read the Workflow page. Reviewers should also read the Reviewer area.
