Pilot material — not validated CEFR data.
This workflow describes a methodological pilot. LLM-generated outputs are provisional Tier 4 candidate material for expert review, not validated CEFR vocabulary data.

Five-stage workflow overview

The project is organised as a staged workflow. The cards below give a short overview. Select a stage to see the detailed inputs, process, outputs, scripts, folder locations, and review considerations.

Stage 1: Corpus preparation

Collect raw corpus files, metadata, licensing notes, and source documentation.

Read more →

Stage 2: Processing and lemma statistics

Tokenise, sentence-split, POS-tag, lemmatise, and calculate frequency, dispersion and ARF.

Read more →

Stage 3: Sampling

Select candidate lemmas and sentence examples using content-word and ARF-based criteria.

Read more →

Stage 4: Function tagging

Run Pass 1, Pass 2 and Pass 3 using the controlled CEFR-derived function taxonomy.

Read more →

Stage 5: QA and expert review

Validate outputs, create review workbooks, record expert comments, and prepare final candidate datasets.

Read more →

How the prompt passes work

The function-tagging workflow uses three LLM prompt passes. Each pass sends one sentence, or one row of previous output, to the OpenAI API with a controlled JSON schema. The model must choose only from the controlled taxonomy.
