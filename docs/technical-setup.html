Technical architecture

ToolRole
GitHubCode, prompts, taxonomy, configuration, notebooks, small samples and documentation.
Google DriveRaw corpora, interim files, outputs, review workbooks and logs.
Google ColabExecution environment that clones GitHub, mounts Drive and runs scripts.
OpenAI APILLM engine for Pass 1, Pass 2 and Pass 3 tagging/aggregation.
NotebookLMExplainer and reviewer-support layer grounded in project sources.

Recommended Colab sequence

  1. Clone the GitHub repository.
  2. Mount Google Drive.
  3. Define REPO_ROOT and DRIVE_ROOT.
  4. Install requirements.
  5. Validate input paths.
  6. Run pipeline scripts.
  7. Save outputs back to Drive.
